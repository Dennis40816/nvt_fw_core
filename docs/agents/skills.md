# Skill assessment

Assess a proposed skill or plugin before installation. Owner approves installation after reviewing the assessment.

Read the full instructions and supporting scripts. Record the following:

- The workflow step that the skill adds or replaces.
- Overlap or conflicts with existing skills and repository rules.
- Instruction length, trigger cost, and additional model calls.
- Commands, scripts, network access, credentials, and permissions it requires.
- Source, version or commit pin, and publication rights.
- A recommendation to adopt it, extract selected rules, or decline it.

Prefer the smallest change that fits the current workflow. Keep installation settings and credentials outside the public repository.

Send the assessment through the owner-question flow in [workflow](workflow.md).

Install only the approved scope. Record the approved source pin and verify that the installed instructions match the assessment.
